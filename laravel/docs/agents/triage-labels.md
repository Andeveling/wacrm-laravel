# Triage Labels

The `triage` skill uses these five canonical labels. Each label string equals its name.

| Label             | Role            |
| ----------------- | --------------- |
| `needs-triage`    | needs-triage    |
| `needs-info`      | needs-info      |
| `ready-for-agent` | ready-for-agent |
| `ready-for-human` | ready-for-human |
| `wontfix`         | wontfix         |
