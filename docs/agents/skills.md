# Skills

Activate the matching skill BEFORE writing code in its domain — not when stuck. A task spanning several domains activates each skill as you enter it. These stacks (Laravel 13, Inertia v3, Tailwind v4, Wayfinder) have breaking changes vs. training data; the skills carry the current APIs.

Each skill's own description states when it fires, and that text is already loaded every turn. This file carries only what a description cannot know about this repo.

## User-invoked only

These are marked `disable-model-invocation`, so they are absent from the model's skill list and run only when the user types `/<name>`. Offer one by name; never assume it ran.

`/ask-matt` routes to the right one when the fit is unclear. `/triage` moves issues through the triage state machine. `/wayfinder` maps work too large for one session into decision tickets, `/to-spec` and `/to-tickets` publish a conversation to the tracker, `/implement` builds from that output. `/grill-me` and `/grill-with-docs` interrogate a plan (the latter writes ADRs and glossary as it goes), `/to-questionnaire` delegates a decision you can't answer, `/wait-what` re-pitches a message that did not land. `/handoff` compacts the session for the next agent, `/teach` explains a concept inside this workspace, `/improve-codebase-architecture` reports deepening opportunities, `/setup-matt-pocock-skills` re-scaffolds the tracker and domain-doc config in `docs/agents/`.

## Name traps

- `wayfinder-development` is Laravel Wayfinder — typed route functions for the frontend. `wayfinder` is planning. Unrelated.
- `worktree` is this repo's own skill, not part of the vendored set: it drives every worktree through Herdr with isolated Sail services and refuses to fall back to raw `git worktree`.

## Where skills live

| Path | Role |
| --- | --- |
| `skills/` | Skills authored here. Edit at this copy. |
| `.agents/skills/` | Vendored copies tracked by `skills-lock.json` (`mattpocock/skills` and local `./skills`). A re-sync overwrites edits made here. |
| `.claude/skills/` | Symlinks into `.agents/skills/` — what Claude Code actually reads. A vendored skill with no symlink is invisible to the agent. |

Boost's own skills (`*-development`, `laravel-best-practices`, `pest-testing`) break that pattern: real directories in both trees, regenerated by `boost:install`. Leave them to Boost.
